# 1. How to Use This Log

This log records every decision made about FindHouseQuick and every point still open. It is read before any new piece of work starts. A decision recorded here may only be changed with the approval of the Managing Director, and any change is added as a new entry with its date. From decision 39 onward, each entry ends with its source. How decisions are recorded is set out in decision 63.
